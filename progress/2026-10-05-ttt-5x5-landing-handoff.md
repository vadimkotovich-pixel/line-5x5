# Handoff — «Линия 5×5» (2026-10-05)

## Состояние: готово и проверено

`C:\!_DSH\ttt-5x5-landing` — самодостаточный мини-лэндинг с игрой. Открывается двойным щелчком
по `index.html`, сервер и сборка не нужны, рантайм-зависимостей нет (jsdom — только для тестов).

| Фаза | Результат | Гейт |
|---|---|---|
| 1. Правила | `assets/js/rules.js`: 48 окон, `L−2` очков, блокировка клеток, два условия конца партии, иммутабельность | 17 тестов |

  265 ничьих на 300 партий (сбалансированно); все партии завершаются.

Единственное изменение после съёмки скриншотов — замена невалидного `role="grid"` без `role="row"`
на `role="group"`: ARIA-атрибуты не влияют на раскладку, поэтому снятая геометрия относится
и к финальной версии.

## Открытые вопросы и риски

1. **Сложность.** Против новичка бот, скорее всего, выиграет (2.5 : 0.5 по замерам). Если это
   отпугивает посетителей лэндинга — снизить уровень можно одной константой: добавить в оценку
   хода долю случайности (например, выбирать не лучший ход, а один из двух лучших с вероятностью 1/3).
2. **Партии низкорезультативны** (около 2 очков на двоих в равной игре) — это следствие
   выбранных правил: три в ряд на 5×5 с вечной блокировкой клеток оборонительны по своей природе.
   Если хочется «крупных счетов», менять надо правила (например, освобождать зачеркнутые клетки
   через ход), но это уже другая игра и требует нового согласования.
3. **Гарантированных ничьих нет**, но при игре двух сильных сторон ничья вероятна (265 из 300).
   Это ожидаемо и не ломает лэндинг: серия партий показывает счет серии.
4. **Не проверено:** Safari/Firefox, реальные телефоны (DPR > 1), screen reader. Вёрстка
   проверялась в Chromium на 1422 и 380 CSS px.

## Как продолжить

- Мелкие правки текста/стилей: `index.html` и `assets/css/styles.css`, затем `npm test` —
  контракт-тест сразу покажет, если класс из разметки остался без стилей или элемент потерялся.
- Правки правил: только `assets/js/rules.js` + `tests/rules.test.js` (там же независимая
  перепроверка очков полным сканированием поля).
- Правки бота: `assets/js/ai.js` + `tests/ai.test.js`; для калибровки — `npm run stats`.
- Визуальная проверка после правок: `npm run visual`, затем команды Chrome из
  `tools/visual-check.cjs` и `node tools/dom-report.cjs`.

## Внимание при работе в этой среде

- `node --test` без `--test-isolation=none` падает с `EPERM` (песочница запрещает порождение
  процессов) — в `package.json` флаг уже стоит.
- Никогда не перезаписывайте файлы проекта через PowerShell `Get-Content`/`Set-Content`:
  русский текст превратится в нечитаемые пары латинских букв с диакритикой. Только Node
  или инструменты записи. Сторож на это — в `tests/ui-contract.test.js`.
- Chrome и Playwright в песочнице не запускаются (crashpad `Access denied`, `spawn EPERM`);
  визуальная проверка требует расширенных прав.
